# Collab with Friends - release assets

This repository hosts the public Windows installers and auto-update packages for
Collab with Friends. The application source tree lives in a separate private
repository.

- Download the latest build from [Releases](https://github.com/Tribbninja/collab-with-friends-releases/releases).
- The desktop updater reads https://collab-with-friends-hub.tribbeisaac.workers.dev/updater.
- Builds are currently unsigned; Windows SmartScreen may warn on first launch.

The hub stores no asset or plugin bytes. Downloads inside the app are
peer-to-peer; this repository only distributes the app itself.
